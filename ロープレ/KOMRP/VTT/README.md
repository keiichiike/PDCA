# VTT保存フォルダ(キックオフ / KOMRP)

キックオフ(KOMRP)ロープレのZoom文字起こし(.vtt)をここに保存する。
ロープレには種類(キックオフ／①／②／③／一次対応)があり、題材が異なるため回ごとにフォルダを分ける。

## 命名規則
`YYYY-MM-DD_相手名.vtt`

例: `2026-10-23_石田さん.vtt`

## 運用
- 動画・音声そのものは保存しない(容量のため)。文字起こしのみ。
- 保存したら `../../PDCAログ.md` の該当エントリに「VTT: (ファイル名)」を記載し、分析結果(フィラー・Q&Aのズレ・時間配分等)を追記する。
- スライド・スクリプト・助成金の想定Q&Aなど、KOMRPの準備資料は1つ上の `KOMRP/` に置く。
