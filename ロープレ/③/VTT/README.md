# VTT保存フォルダ(定例相談会③)

定例相談会③のZoom文字起こし(.vtt)をここに保存する。
ロープレには種類(キックオフ／①／②／③／一次対応)があり、題材が異なるため回ごとにフォルダを分ける。
他の回のフォルダが必要になったら `定例相談会/<回>/VTT/` として同様に作る。

## 命名規則
`YYYY-MM-DD_相手名.vtt`

例: `2026-08-27_日尾さん.vtt`

## 運用
- 動画・音声そのものは保存しない(容量のため)。文字起こしのみ。
- ③の題材はネタバレになりうるので、他の人と共有・配布しない。
- 保存したら `../../PDCAログ.md` の該当エントリに「VTT: (ファイル名)」を記載し、分析結果(フィラー・ゴールすり合わせ等)を追記する。
