# 助成金:「就業時間内」の定義(西さんとのすり合わせ)

出典: KOMRP 西さん 1回目(10/16)・2回目(10/20)・3回目(10/21)のVTT(`VTT/`)。
主にすり合わせたのは **1回目(10/16)の最後**。西さんが「直近の助成金変更アナウンス」を画面共有しながら説明した。

## 結論
**就業時間内 = 定時(所定労働時間)内。「賃金が出ていればOK」ではない。**

| ケース | 案内 | 根拠 |
|---|---|---|
| 平日の定時内 | OK | 10/16 |
| 土曜が定時の会社(例: 土曜9〜12時が所定) | その時間内ならOK | 10/16 |
| 残業時間 | 原則NG。管理職・みなし残業など判断が分かれるケースは「**事前に労働局へ直接確認**」と案内 | 10/16(変更アナウンス) |
| 休日出勤(定時ではない日曜など) | やらない方がいい。実際に助成金が下りなかった企業がある。どうしてもなら労働局に確認 | 10/21 |
| 2回目以降の視聴・復習を土日にする | NG(以前は「1回目のログしか出さないから可」という案内も一部あったが、審査が厳しくなったので不可) | 10/16 |
| 定時を数分過ぎて動画が開いていた | 弊社から確実なことは言えない(労働局で見解が違う)。細かく管理しているところは少ないと思うが、心配なら労働局に確認。前提として超えないように | 10/16・10/21 |
| 休日に生成AIを触る(講座動画は開かない) | 履歴管理の範囲外なので可(2回目で池松さんが回答、指摘なし) | 10/20 |

## やってはいけない説明
- 「**賃金が支払われている時間 = 就業時間**」と言うこと(10/20 西さん)。
  残業や休日出勤も賃金が出るので、お客さんが「じゃあ残業時間・休日出勤で見ていいよね」と勘違いする。
  変更前のルール(賃金が出ていれば残業も可)のまま話している状態。
- 質問と違う話をすること(10/21)。「17:30定時で5分過ぎたら一発アウト?」に、休日の話で答えてしまった。

## 答え方の型(10/21 西さん)
回答集に当てはめず、質問を最後まで聞いてから
**「これはOK」「これはダメ」「これは労働局に確認してください」** のどれかがシンプルに伝わるように答える。

## 一緒に押さえること(同じ回で出た重要点)
- 最低学習時間は **受講者全員がそれぞれ10時間以上**(「1人1時間以上・全員で10時間」は古い情報。10/20 西さん「だいぶクリティカル」)。
- 時間は視聴時間ではなく、修了した講座の標準学習時間の合計(修了 = 修了テスト合格)。
- ただし **修了テストの合格だけでなく、全動画の視聴も必要**(視聴していないケースもチェックされる。10/20)。
- 受講者全員分がチェックされる。
